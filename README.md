# Seiigcm

Preciso de um criador automático de documentos, um site que consiste em apenas eu mandar informações para preencher automaticamente um formato pré definido de documento. Seria documento ofício nesse estilo. Geralmente usarei pra fazer ofícios de gravações como padrão. Deve ser responsivo, interno, controlado de acesso único. Deve conter campos pré definidos para preencher o documento com auxílio de IA para poder revisar ortografia e o melhor texto possível para compor o documento.
